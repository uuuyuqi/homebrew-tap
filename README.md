# Homebrew Tap for TooToo

Official Homebrew Tap for [TooToo](https://github.com/uuuyuqi/tootoo) — zero-dependency local AI coding telemetry console & macOS menu bar pet.

## Install

```bash
brew install --cask uuuyuqi/tap/tootoo
```

## Upgrade

```bash
brew upgrade --cask tootoo
```

## Uninstall

```bash
brew uninstall --cask tootoo
```
